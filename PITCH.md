# Пітч ~90 с — СільпоSE

Дедлайн хакатону: відео 3–5 хв. Каркас першої хвилини.

1. **Проблема (12 с).** Машрум радить у чаті. Гостю потрібен **додаток життя**: тренування + стеля грошей, не лише «що на вечерю».
2. **Home (10 с).** Бренд **СільпоSE** → спочатку Sport («Пігнали»), нижче Express («Замовити»).
3. **Sport (20 с).** Програми → день: сесія, тарілки з полиці, кроки.
4. **Express (35 с).** Pulse витрат → чеклист (чек / групи / qty ±) → гаманець-чек → **Погодити** → долив у **живий кошик Сільпо** + лінк оформлення (після логіну).
5. **MCP (13 с).** Токен на сервері. Без логіна — фікстура. Write лише на явний Погодити / cart push.

## Jury path (~60–90 с)

`http://127.0.0.1:8766/#/` → Sport pulse → Express pulse → **Замовити** → qty ± → Списки / База+ → **Погодити** (з логіном — кошик Сільпо).
