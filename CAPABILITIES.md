# СільпоSE — що вміє додаток (MVP)

Опис продуктового функціоналу прототипу **СільпоSE** (Sport + Express).  
Живе демо: [silpo-se.vercel.app](https://silpo-se.vercel.app/)  
Код: `prototype/` у цьому репозиторії.

Це **capability sheet** для MVP: що користувач може зробити сьогодні.  
Технічні деталі UI — у `prototype/DESIGN.md`; демо-скрипт — у `PITCH.md`; запуск — у `README.md`.

---

## 1. Що це

**СільпоSE** — мобільний web-прототип (phone-shell ~430px) із двома ритуалами під одним брендом:

| Продукт | Для чого |
|--------|----------|
| **СільпоSport** | Тренування «сьогодні»: програма, сесія, страви дня, прогулянка до магазину |
| **СільпоExpress** | Список покупок із чеків і полиці Сільпо → **Погодити** → долив у живий кошик silpo.ua |

Без логіну працює в **демо** (fixtures). Після OTP-входу в Сільпо — живі чеки, ціни/SKU з MCP і запис у кошик.

---

## 2. Екрани (навігація)

| Маршрут | Екран | Коротко |
|---------|--------|---------|
| `#/` | Home | Два входи: Sport і Express + пульси місяця |
| `#/sport` | Sport | Профіль тіла (якщо треба) → вибір програми |
| `#/day` / `#/day/YYYY-MM-DD` | День | Сесія, страви, walk; грати сесію можна лише **сьогодні** |
| `#/survey` | Смаки | Уподобання раціону (фільтри полиці) |
| `#/shop` | Express | Чекліст, бюджет, swap/add, Погодити |
| `#/shop/add…` | Додати | Каталог / пошук SKU у групу |
| `#/shop/lists…` | Списки | Чеки та збережені «бази» |
| `#/shop/receipts/{id}` | Чек | Рядки чека → влити в список |
| `#/shop/bases/{id}` | База | Збережений список на пристрої |

Оверлеї без окремого «екрана»: заміна товару (swap), збереження бази, очікування після OAuth, busy-veil під час resolve / push.

## 3. Функціонал по зонах

### 3.1 Home

- Бренд **СільпоSE** і статус MCP: «Увійти» / підключено / демо.
- CTA: **Пігнали** (Sport), **Замовити** (Express).
- **Sport-пульс**: місяць, покриття днів/раціону, орієнтир сесій, перехід у день.
- **Express-пульс (гаманець)**: витрати vs орієнтир, sparkline, піки/підказки, топ SKU, позначки «зайве», редагування місячної цілі, шорткати в магазин / чек / списки.
- (Опційно) партнерський контент через `?partner=` (fixture chef).

### 3.2 СільпоSport

**Профіль**

- Стать, вік, зріст, вага, ціль тіла → евристичний kcal-орієнтир (не медконсультація).

**Програми**

- Колесо / список програм з KB; фільтр за метою (cardio / strength / mobility); рівні beginner|intermediate.
- Ранжування під профіль; outdoor-програми в даних є, у піку home **не пропонуються**.

**День сесії**

- Плеєр: таймер, Старт / Далі / Пауза / +30 с, підготовка/відпочинок, арт вправи, howto + TTS «Слухати», гід, мозаїка завершення.
- Контроли сесії вимкнені для днів **не сьогодні** (календарний перегляд).

**Прогулянка**

- Пресет кроків (4k / 6k / 8k).
- «Карта до Сільпо»: Leaflet + маршрут пішки (потрібен логін; `POST /api/walk-map`).

**Страви дня**

- Сніданок / обід / вечеря з meal map програми.
- Режим плити: варити vs готове; фільтр від «Смаків».
- Додати прийом(и) в Express з provenance «з програми».

**Смаки (`#/survey`)**

- Уникати (молоко, яйця, риба, курка, йогурт тощо), вегетаріанство, режим готування.
- Збереження впливає на полицю дня; дисклеймер «не медпорада».

### 3.3 СільпоExpress

**Список**

- Горизонт (тиждень тощо) і **стеля бюджету** ₴.
- Soft-список одразу, потім підвантаження live SKU зі Сільпо (список блокується + veil «підвантажуємо»).
- Групи полиці: хліб, білок, овочі, молочне, extra, алкоголь, консервація, clean, tobacco…
- Галочки «у чеку», кількість ±, прибрати, **заміна**, **+ додати** з каталогу/пошуку.
- Шапка-гаманець: сума, залишок, розклад потрібне / настрій / «ваше зайве».
- Підказка **Шафа** (pantry): сигнали з історії покупок, не інвентар холодильника.
- Полиця «нещодавно купували»; банер handoff зі Sport.

**Погодити → кошик**

- Кнопка **Погодити N** шле прийняті live SKU в кошик Сільпо (`POST /api/cart/push`, merge).
- **Merge без подвоєння**: уже наявні в потрібній кількості не дублюються; додається лише дельта.
- Після успіху: нова вкладка silpo.ua / checkout-лінк; CTA **Додати ще** для повторного долива; лінк «Відкрити на silpo.ua».
- Оплата і слот доставки — **лише в Сільпо**, не в цьому додатку.

**Списки: чеки і бази**

- **Чеки**: історія (live або fixture) → вибрати рядки → влити в чекліст + undo ~5 с.
- **Бази**: зберегти поточний список / з чека на пристрої (`localStorage`, до ~20); застосувати merge/replace. **Не** синхронізуються з акаунтом Сільпо.

### 3.4 Вхід у Сільпо (MCP)

- OAuth + OTP через `/auth/start` → callback; на Vercel — cookie-сесія; локально — `.token.json`.
- Без токена: демо-полиця і fixture-чеки.
- З токеном: жива історія, resolve/browse/replacements, запис кошика, walk-map.
- Вихід: `POST /api/auth/logout`.

## 4. Типові сценарії (happy paths)

1. **Швидкий Express (~1–2 хв)**  
   Home → Замовити → підправити галочки/к-сть → (опційно) база/чек → Увійти → **Погодити** → вкладка silpo.ua.

2. **Sport → паливо → кошик**  
   Пігнали → профіль → програма → Смаки → день → сесія/страви → Додати в Express → допрацювати список → Погодити.

3. **Повторити чек**  
   Пульс або Списки → чек → обрати позиції → влити → undo за потреби → Погодити.

4. **Прогулянка до магазину**  
   День → пресет кроків → Карта до Сільпо (після логіну).

5. **Другий долив**  
   Після першого Погодити → **Додати ще** (або змінити список → знову Погодити) → merge лише нових/дельти.

## 5. Джерела даних

| Джерело | Навіщо |
|---------|--------|
| `content/kb.json` | Програми, сесії, meal maps |
| `content/shelf.json` | Fixture-полиця без MCP |
| `content/fixture-orders.json` | Демо-чеки |
| Silpo MCP | Історія, пошук/каталог, resolve SKU, кошик, walk-map |
| `localStorage` | Профіль, смаки, бази, цілі місяця, waste-мітки, кроки walk, події сесії |

У цьому прототипі **немає** графіків відключень світла / DTEK.

## 6. Чого MVP свідомо не робить

- Нативний застосунок (лише web phone-shell).
- Оплата, checkout, вибір слота/гілки доставки всередині SE (лише handoff у Сільпо).
- Правда про холодильник / залишки вдома (Шафа = підказка з чеків).
- Хмарні «бази» в акаунті Сільпо; спільний сімейний профіль.
- Автозапис у кошик при кожній зміні qty (запис лише на **Погодити** / **Додати ще**).
- Медичні / дієтологічні рекомендації.
- Повноцінний CMS партнерів (лише fixture-партнер).
- Deep-link пошутового пошуку в URL.

---

## 7. Технологія (одним рядком)

Vanilla ES-module SPA (`index.html` + `js/app.js` + `css/app.css`) + Node/`api/gateway.js` як проксі до **Silpo MCP** (OAuth), локальний compose/gate/resolve; Leaflet для карти walk; без React-додатка.
